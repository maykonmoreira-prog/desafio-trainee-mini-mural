# Mini Mural Corporativo - Projeto Trainee

## Sobre o projeto

Esse repositório contém o código-fonte para a implementação de um aplicativo que possui o pretexto de ser uma rede social corporativa, ou mini mural corporativo - se assemelhando ao X/Twitter.

O back-end será implementado usando o ambiente NodeJS, para possibilitar o uso de Java Script fora de um Navegador Web. Para o front-end, o React Native será utilizado.

## Arquivos adicionados

Até o momento, está alterado apenas o .gitignore, que define quais arquivos não serão commitados e enviados para o servidor GitHub. Para rodar o código na sua própria máquina, será necessário a instalação de algumas dependências, para isso é usado, no terminal, o código "npm install". Com isso, todas as dependências que estão registradas em package.json serão instaladas.
